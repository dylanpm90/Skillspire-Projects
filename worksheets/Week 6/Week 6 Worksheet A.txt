6. Convert the previous inheritance example into a composition example by giving Car a private Engine with start() and printing both start + “Car ready”. (Write class headers + key methods only.)

class Horn {
    void honk() {
        System.out.println("Car honks");
    }
}

class Engine {
    void start() {
        System.out.println("Car is ready to drive");
    }
}

class Vehicle {
    Engine engine;
}

class Car extends Vehicle {
    private Engine engine;
    Horn horn;

    Car() {
        this.engine = new Engine();
        this.horn = new Horn();
    }

    void start(){
        engine.start();

    }
    void honk(){
        horn.honk();
    }
}


public class Main {
    static void main(String[] args) {
        Car c = new Car();
        c.start();
        c.honk();
    }
}

12. Which one tends to keep hierarchies shallow and systems modular: inheritance or composition?

Composition oriented design schemes tend to have shallower hierarchies and modular systems.
