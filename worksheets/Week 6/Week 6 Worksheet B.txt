1. What does abstract mean for a class? Can you instantiate it?

	Abstract classes are classes which have abstract methods without a body or can have concrete methods with a body which can serve as base classes for subclasses. You cannot instantiate abstract classes.

3. Create Circle extends Shape with field r and implement area() as Math.PI * r * r.

public class AbstractShapes {
    abstract class Shape {
        abstract double area();
        void describe(){
            System.out.println("This is a shape");
        }
    }

    class Circle extends Shape{
        double r;

        @Override
        double area() {
            return Math.PI * r * r;
        }
    }

    void main(String[] args) {
        Circle circle = new Circle();
        circle.r = 3;
        double circleArea = circle.area();

        System.out.println(circleArea);
    }
}

24. Design prompt: When would you pick an abstract base class and interfaces together? Give a 1–2 line scenario.

It's a good idea to use abstract base classes and interfaces when the object you're trying to put together has an "is-a" relationship with a superclass and a "can-do" relationship with an interface.
A car inherits from an abstract Vehicle class, which has driving and sound methods because a car "is-a" vehicle. The car can implement a GPS interface and horn interface for its methods, because the car object "can-do" navigation with the GPS and "can-do" a honk with the horn.


25. Briefly explain why excessive tiny interfaces (“interface pollution”) can harm code readability.

Too many small interfaces clutter the file structure and can muddy the waters on their purpose and usage.
