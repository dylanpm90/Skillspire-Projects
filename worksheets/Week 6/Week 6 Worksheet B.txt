1. What does abstract mean for a class? Can you instantiate it?

	Abstract classes are classes which have abstract methods without a body or can have concrete methods with a body which can serve as base classes for subclasses. You cannot instantiate abstract classes.

3. Create Circle extends Shape with field r and implement area() as Math.PI * r * r.

public class AbstractShapes {
    abstract class Shape {
        abstract double area();
        void describe(){
            System.out.println("This is a shape");
        }
    }

    class Circle extends Shape{
        double r;

        @Override
        double area() {
            return Math.PI * r * r;
        }
    }

    void main(String[] args) {
        Circle circle = new Circle();
        circle.r = 3;
        double circleArea = circle.area();

        System.out.println(circleArea);
    }
}


4. What is an interface? In one sentence.

	An interface is like a contract which promises the methods within will be filled out.

5. Define an interface Playable with method play(). Implement it in Guitar and Piano (print a line in each).

public class InstrumentPlayability {
    interface Playable{
        void play();
    }

    class Piano implements Playable{
        @Override
        public void play() {
            System.out.println("Playing 'Fur Elise'.");
        }
    }

    class Guitar implements Playable{
        @Override
        public void play() {
            System.out.println("Playing 'Stairway to Heaven'.");
        }
    }

    void main(String[] args) {
        Guitar guitar = new Guitar();
        guitar.play();

        Piano piano = new Piano();
        piano.play();
    }
}
