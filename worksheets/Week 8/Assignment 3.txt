# Assignment 3: Creating REST Controllers and Mapping HTTP Methods

**Topic:** Spring REST — Controllers & HTTP Methods

## Overview
Turn your JPA-backed application into a RESTful API by building controllers that expose CRUD operations over HTTP.

## Instructions
1. Add `spring-boot-starter-web` to your project (if not already present).
2. Create a `ProductController` (`@RestController`) that exposes the following endpoints:
   - `GET /api/products` — returns all products.
   - `GET /api/products/{id}` — returns a single product by ID.
   - `POST /api/products` — creates a new product from a JSON request body.
   - `PUT /api/products/{id}` — updates an existing product.
   - `DELETE /api/products/{id}` — deletes a product by ID.
3. Use the appropriate mapping annotations: `@GetMapping`, `@PostMapping`, `@PutMapping`, `@DeleteMapping`.
4. Return appropriate HTTP status codes using `ResponseEntity` (e.g., `200 OK`, `201 Created`, `404 Not Found`, `204 No Content`).
5. Test every endpoint using Postman, curl, or a similar tool, and capture screenshots or terminal output of each request/response.

## Requirements
- Controller must delegate business logic to a `ProductService` (do not put repository calls directly in the controller).
- Handle the "not found" case for `GET`, `PUT`, and `DELETE` by returning `404`.
- Include a brief Postman collection or a list of example curl commands in your README.

## Submission
Submit your project (zip or GitHub link) plus your test evidence (screenshots or a text file with request/response pairs).
