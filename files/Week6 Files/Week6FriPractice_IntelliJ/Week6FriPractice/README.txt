Week 6 Friday practice: IntelliJ project

1. Unzip this file.
2. In IntelliJ: File > Open, select the Week6FriPractice folder (the one that contains src), and click Open.
   If asked, choose "Trust Project".
3. If a yellow bar says "Project JDK is not defined", click "Setup SDK" and pick any JDK 17 or newer.
4. Open src/week6/fri/practice/Week6FriPractice.java and click the green Run arrow next to main,
   or pick "Week6FriPractice" next to the Run button at the top.

The file compiles and runs as given. Do each TODO when Sean says so.
